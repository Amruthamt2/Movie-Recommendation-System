# Movie Recommendation System

A machine-learning-based movie recommendation system developed using Python and Streamlit.

## Features

- Movie recommendations based on user preferences
- User-based recommendation
- Item-based recommendation
- Cosine similarity
- Interactive Streamlit interface

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Purpose

The project demonstrates the application of machine learning and recommendation techniques to provide personalized movie suggestions.
